- 未発見 `?` への接触による自動発見
- 発見時の代表画像全画面表示
- 発見後の `センターへ入る` / `あとで`
- 発見済み施設アイコン＋遺産名ラベル
- 再訪時の `センターに入る` / `戻る`
- センター退出時の施設位置復帰と、退出直後の再発火抑止
- 全27遺産で同一の研究センターレイアウト
- 本棚 / 調査員 / 展示 / 腕試し / 出口

- 問題・正答固定、選択肢のみランダム

- センター訪問中も全国マップ iframe を破棄せず保持し、退出時の再ロードを回避

## 先祖帰り防止確認

今回のベータ実装では以下を変更していない。

- `japan-6x-map-lab.html` の6倍マップ本体
- `docs/phase9-map-ux-decisions.md` の確定済み地図方針
- `tutorial-lab.html` のチュートリアル本体
- `tutorial-lab-final.html` の確定済みピラミトン表示

チュートリアルには外側から「主人公名の保存」「完了状態保存」「全国マップへの接続」だけを追加する。

研究センターの成長・レベル・マスター等の過去の設計案は削除せず、ベータのランタイムからのみ外している。

## 自動検査

`scripts/validate-beta.mjs` と `.github/workflows/beta-check.yml` を追加。

静的検査項目:

- 学習データが27件あること
- ID 1〜27がそろうこと
- 腕試しが各3問、合計81問あること
- 正答が選択肢内にあること
- 登録基準をローマ数字だけで表示していないこと
- 全27遺産に画像3枚以上＋代表画像があること
- 画像ファイルがリポジトリに存在すること
- `beta.html` / `area-map-game.html` / `research-center-game.html` のインラインJavaScript構文
- ベータランタイムに旧センター成長キーが残っていないこと
- 承認済み6倍マップ・チュートリアル基準ファイルが存在すること

## 残る確認

コード実装後にブラウザ実行で次の Golden Path を通し、ここがすべて通ればベータ完成扱いとする。

- [ ] タイトル → チュートリアル
- [ ] 名前が保存される
- [ ] チュートリアル → 北海道最北端付近
- [ ] `?` 接触 → 自動発見
- [ ] 代表画像 → `センターへ入る` / `あとで`
- [ ] 本棚 / 調査員 / 展示 / 腕試しを自由順で体験
- [ ] `!` → `✓` と保存
- [ ] 出口 → 施設と同じ位置
- [ ] `?` → 施設アイコン＋遺産名ラベル
- [ ] 再訪で発見演出をスキップ
- [ ] 別遺産でも同じループが成立
- [ ] ブラウザ再読み込み後に現在地・発見・体験状態を復元
- [ ] iPad横向きで操作不能や画面外要素がない
