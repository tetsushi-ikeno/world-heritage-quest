## ベータ版の目的

まず「最初から最後まで不具合なく遊べる一本の体験」を完成させる。

Golden Path:

1. チュートリアル
2. 北海道最北端付近から全国マップへ
3. 全国を自由移動
4. 未発見の `?` に触れる
5. 発見演出＋代表画像を全画面表示
6. `センターへ入る` / `あとで` を選ぶ
7. 研究センター内を自由探索
8. 本棚・調査員・展示・腕試しを任意順で体験
9. 体験状態を自動保存
10. 出口から全国マップへ戻る
11. `?` が施設アイコン＋遺産名ラベルに変わる
12. 再訪時は発見演出をスキップし、`センターに入る` / `戻る` を選ぶ
13. 別の世界遺産でも同じループを体験できる

この一連が複数遺産で安定して動けばベータ完成とする。

## 先祖帰り防止ルール

### 全国マップ

`japan-6x-map-lab.html` と `docs/phase9-map-ux-decisions.md` を基準とする。

- 縮尺は 6倍固定
- 27遺産の全国配置を維持
- 主人公中心の追従方式を維持
- 実地理を意識した代表的な山脈・平野・森林を維持
- 遺産周辺だけ草原化する方針を維持
- 北固定ミニマップと密集地点のクラスタ表示を維持
- 全国は開始時から全域自由移動

ベータ実装のために変更してよいのは、保存位置の復元など Golden Path に必要な最小限の外部 API の追加のみ。地形・縮尺・配置・描画・操作感を再設計しない。

### チュートリアル

`tutorial-lab-final.html` を承認済み基準とする。

- 既存の画面構成・説明・ピラミトン表現を維持
- ベータで追加するのは主人公名保存、完了状態保存、全国マップへの接続だけ
- 新たな説明や画面追加はしない

### 研究センターの成長仕様

過去に決めた研究センターの成長・レベルアップ・マスター等は将来案として残すが、**ベータ版のランタイムには入れない**。

ベータでは全27センターを同一レイアウトとし、レベル・成長・報酬・マスター・地方試験・達成率は使用しない。

これは過去仕様の破棄ではなく、ベータ完成後のフェーズへ延期するためのスコープ制御とする。

### 3. 発見・再訪フロー

- [x] 未発見の `?` に初めて触れたら自動発見

- [x] 再訪時は発見演出を出さない

### 4. 共通研究センター

- [x] 全27遺産で同一レイアウト

- [x] 好きな順で体験可能

- [x] 右側の共通アクションボタンを使用
- [x] 本棚=`しらべる`
- [x] 調査員=`はなす`
- [x] 展示=`みる`

### 5. 学習コンテンツ

- [x] 本棚: 登録年＋登録基準
- [x] 登録基準はローマ数字だけにせず `基準2：文化交流` のように意味を併記
- [x] 調査員: 歴史的背景・関連人物・出来事
- [x] 展示: 遺産の特徴＋画像3枚
- [x] 代表画像1枚を発見演出と展示で共用
- [x] 説明文はスクロールやページ送りを原則不要とし、1画面に収める
- [x] 目安は2行程度（必要なら3行まで）

### 6. 腕試し

- [x] 各遺産3問程度
- [x] 問題と正答は固定
- [x] 選択肢の順番だけ毎回ランダム
- [x] 登録基準の問題を含める
- [x] 遺産の特徴の問題を含める
- [x] 回答直後に正誤を表示
- [x] 不正解時は正解を表示
- [x] 1〜2文の短い解説
- [x] 3問終了後に `3もん中2もん正解！` のように得点のみ表示
- [x] 3問すべて回答した時点で腕試しを体験済みにする
- [x] 不合格・ランク・報酬・最高得点保存は実装しない

### 7. 起動フロー

- [x] セーブなし: タイトル→チュートリアル→全国マップ
- [x] セーブあり: タイトル→`つづきから`→保存位置
- [x] チュートリアル完了後は再実行しない
- [x] `はじめから` は通常メニューに置かず、データリセット後のみ最初から開始

- UX演出の追加
- 学習効果の検証と文章改善

- 研究センターの成長、レベル、マスター、やり込み要素

- 遺産の書の本格実装
