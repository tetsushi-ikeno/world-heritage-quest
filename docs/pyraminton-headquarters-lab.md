# ピラミトン本部 専用Lab

固定URL: `pyraminton-headquarters-lab.html`

## 管理方針
- 通常の連番Labとは別枠の恒久Labとして管理する。
- このチャットでは本部のレイアウト・動線・操作UIのみを扱う。
- 遺産グラフィック自体の制作・確定・GitHub保存は別チャットの方針に従う。
- 別チャットでグラフィックが正式確定した場合、この本部Labはその確定済み正本を参照する形で更新する。
- 未確定のものは立て札のままとする。

## r20260830-10 接続不具合の根本対策
- 旧版は部屋床と通路の両方にプレイヤー半径分の内側判定を入れ、見た目では接続していても数pxの「見えない隙間」が発生していた。
- 歩行可能領域を「すでに壁厚を除いた室内床 + 部屋へ深く重なる通路」の和集合として再定義し、二重の余白計算を廃止。
- 通路を壁より前面に描画し、「通路なのか壁なのか」が視覚上も明確になるよう統一。
- 中央ホールから北海道・西日本・東日本・九州沖縄の4エリアへBFSで到達できることをページ読み込み時に自動チェック。接続失敗時は赤い警告を表示する。
