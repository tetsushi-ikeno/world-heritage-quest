# ピラミトン本部 専用Lab

固定URL: `pyraminton-headquarters-lab.html`

## 管理方針
- 通常の連番Labとは別枠の恒久Labとして管理する。
- このチャットでは本部のレイアウト・動線・操作UIのみを扱う。
- 遺産グラフィック自体の制作・確定・GitHub保存は別チャットの方針に従う。
- 別チャットでグラフィックが正式確定した場合、この本部Labはその確定済み正本を参照する形で更新する。
- 未確定のものは立て札のままとする。
