# 世界遺産 展示グラフィック制作基準 v1.1

更新日: 2026-08-30

> **この文書を研究センター展示グラフィックの正本ルールとする。**
> 旧Lab・旧SVG・別チャットの試作ルールと内容が衝突した場合は、本書と `docs/heritage-graphics-decisions.md` を優先する。

## 目的

研究センターに入った瞬間に、展示物を見て「どの世界遺産か」が分かり、27遺産を並べても相互に区別できることを最優先とする。

## 共通ビジュアル

- 研究センター内の **4×4マス相当** を基本サイズとする。
- 実物の形状・プロポーション・代表的特徴をできるだけ保つ。
- 写真風ではなく、ゲーム内展示物として統一した **フラット〜穏やかなペイント調** とする。
- 輪郭に白縁をつけ、柔らかい落ち影を加える。
- 背景は透明を基本とし、1つの「ミニチュア展示物／ジオラマ」として成立させる。
- 小サイズで読めない細密描写より、主役となるシルエット・構造を優先する。
- 画像外の名称ラベルとは別に、画像内にも短い識別文字を入れる。

## 表現方式

### A. 単体ランドマーク型
代表的な建造物・像・山など、単体で識別しやすいもの。

### B. 景観ジオラマ型
自然遺産など、地形・植生・水・生物を組み合わせて表すもの。

### C. 複合モチーフ型
複数の構成資産や要素を1つの小さな展示物にまとめるもの。

### D. 断面・ストーリー型
鉱山や考古遺跡など、地上の外観だけでは価値が伝わりにくいもの。

## 画像内の識別文字ルール

### 基本

- **全遺産に、識別しやすい2〜数文字程度の短い文字情報を入れる。**
- 1文字への統一や厳密な文字数統一は行わない。読みやすさ・識別しやすさを優先する。
- 正式名称を画像内に書くのではなく、展示物の一部として短く配置する。
- 石碑、札、刻印、看板など、その展示物の世界観に自然に馴染ませる。
- 画像外には従来どおり正式名称またはゲーム用表示名を別途表示する。

### 文字の選び方

地名・建物名・文化名のどれかに統一せず、**そのグラフィックを最も早く識別できる語を優先する。**

優先順位の目安:
1. 誰でも分かりやすい代表建造物・代表地名
2. 遺産を特徴づける文化・時代・機能
3. 構成資産のうち、今回グラフィックで主役として描いているもの

例:
- 古都京都の文化財 → `金閣寺`
- 古都奈良の文化財 → `奈良`
- 石見銀山 → `石見`
- 佐渡島の金山 → `佐渡`
- 明治日本の産業革命遺産 → `軍艦島`
- ル・コルビュジエの建築作品 → `西洋美術館`
- 原爆ドーム → `広島`
- 長崎と天草地方の潜伏キリシタン関連遺産 → `長崎`
- 百舌鳥・古市古墳群 → `百舌鳥`

## 水景の扱い

- **水・川・池・海は、その遺産の実際の景観・構造・識別要素として必要な場合のみ描く。**
- 『ジオラマとして見栄えがよい』『画面下部を埋めやすい』という理由だけで水を追加しない。
- 実際に水辺でない建造物や遺産は、石畳、土、芝、庭園、岩、植栽など実態に合った地表表現を使う。
- 水を積極的に使う例: 厳島、知床、小笠原、沖ノ島、紀伊山地の那智滝、百舌鳥の周濠。
- 水を無理に加えない例: 平泉、原爆ドーム、寺院・建築物系の展示。

## 自然遺産

- 単なる「森」「山」にならないよう、地形・植生・水・生物の組み合わせで差別化する。
- 固有種・希少種がその遺産の価値を理解するうえで重要な場合は、代表種を展示内に含める。
- 生物だけをマスコット化せず、遺産全体の景観の中に自然に配置する。
- 確定例:
  - 小笠原諸島: 海洋島景観＋固有の陸産貝類
  - 奄美大島・徳之島・沖縄島北部・西表島: 亜熱帯林＋イリオモテヤマネコ
  - 屋久島: 巨大な屋久杉＋苔・森
  - 白神山地: ブナ原生林＋渓流＋識別文字 `白神`
  - 知床: 流氷・海岸・山＋ヒグマ

## 鉱山系

石見銀山と佐渡金山は、同じ鉱山カテゴリであることを感じさせつつ、対比して識別できるようにする。

- 石見銀山: 森に覆われた山、断面坑道、山あいの町並み。識別文字 `石見`。
- 佐渡金山: 道遊の割戸、露出した山肌、断面坑道。識別文字 `佐渡`。

## 制作・確定運用

1. 約6件ずつ制作する。
2. 研究センターで4×4表示したときの識別性を確認する。
3. 修正対象は「未確定」のまま残す。
4. ユーザー確認後にのみ「確定」へ変更する。
5. 確定後の内容は `docs/heritage-graphics-decisions.md` に記録する。
6. 新しい案が既存確定内容と衝突する場合は、確定内容を勝手に置き換えず明示的に再確認する。
7. 確定済みグラフィックは、明示的な修正要求がない限り再生成しない。

## 現在の状態

2026-08-30時点で、**日本の世界遺産27件すべての個別展示グラフィックを確定済み**。
今後の主工程は、全27件を研究センターへ配置した状態での4×4表示・iPad横向き最終確認と、正式アセット配置・実装統合である。

## 旧ルールとの関係

`docs/cultural-heritage-exhibit-style.md` は初期SVG/Lab制作時の記録として保持するが、今後の新規制作における正本ルールではない。既存の確定SVGを参照する場合も、本書の統一ルール（特にジオラマ表現、識別文字、水景の扱い）を優先する。
