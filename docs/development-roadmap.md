## Phase 9 — ゲームUI / UX基準の確定【NEXT】

Phase 8でゲーム全体の骨格が通ったため、Phase 9では**現在のGolden Pathを子どもが迷わず・楽しく操作できるゲーム画面に整える**。

### 主対象

#### 全国マップ
- HUDの情報量・配置を整理
- 現在地、調査進捗、メニュー等の必要情報を確定
- `?`、研究センター、主人公の視認性を調整
- 接近時の `しらべる` / `入る` の表示方式を確定
- iPad横向きでのスティック、タップ領域、マップ表示面積を調整

#### 研究センター
- メッセージウィンドウの位置・サイズ・文字階層を確定
- `読む` / `しらべる` / `はなす` のアクションUIを統一
- 調査済み / 未調査を迷わず判断できる表現を検討
- 入口・出口・主人公・調査対象の視認性を調整
- 全国マップと同じ操作感になるよう入力UIを統一

#### 共通UI
- チュートリアルのデザインを基準に、本編の色・文字・ボタン・メッセージ表現を統一
- ピラミトンをどこまで常時表示するか整理
- 不要な説明を減らし、次に何をすればよいか自然に分かる導線へ調整

### Phase 9でまだ作り込まないもの

- 問題・クイズの本格組み込み
- 調査記録 / 図鑑の本格実装
- 全27遺産へのコンテンツ展開
- 効果音・BGMの最終調整
- 細かなセリフの最終稿
- 最終的な演出磨き込み

これらは、Phase 9でゲームUIの基準を確定した後のフェーズで順次追加する。

## 開発方針

- 学習教材をゲーム風に装飾するのではなく、「RPGを遊んでいるうちに世界遺産を覚える」体験を優先する。
- 大きな方向変更は後回しにせず、次フェーズへ進む前に判断する。
- Labで単機能を検証 → APPROVED → ゲーム画面へ統合 → Golden Path確認 → Main反映、の順で進める。
- UIの細部は骨格が成立した後にまとめて調整する。
- 問題はAIでリアルタイム生成せず、事前整備した問題JSONを利用する。
- プレイヤー進行データは最終的にLocalStorage等へ永続化する。Phase 8の統合Previewでは確認用にsessionStorageを使用している。
