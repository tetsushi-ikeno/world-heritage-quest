# 世界遺産検定 過去問題JSONの使い方メモ

## 対象ファイル

`data/sekaken_4_2024_03_rpg.json`

提供された紙面画像から、世界遺産検定4級・2024年3月実施分の50問をRPG用のJSONデータに整理したものです。

※ 当初「2025年3月実施」として扱う案がありましたが、解答・正答率ページに「2024年3月」と明記されていたため、データ上の出典は `世界遺産検定4級 2024年3月実施` としています。

## 基本方針

元の検定問題には、前段の文章を読んで下線部について答える問題、空欄補充、写真・地図を見て答える問題があります。

RPGでは各問題を単独で出題できるよう、次の方針で整理しています。

- 下線部参照だけが不要な問題は、「下線部(a)に関し」などの表現を削除
- 前段の文章がないと成立しない問題は、必要な情報だけを問題文へ移植
- 空欄補充問題は、同じ知識を直接問う4択問題へ変更
- 写真に名称が添えられており、文字選択肢に置き換えても同じ知識を問えるものは文字化
- 地図・写真そのものの識別が問題の本質であるものは `採用: false` として除外

今回の除外対象は元問題番号 `19`, `37`, `44` です。

## JSON構造

トップレベルは次の2項目です。

- `メタデータ`: 出典、難易度基準、採用ルールなど
- `問題`: 50問分の配列

各問題には主に以下の項目があります。

| 項目 | 内容 |
|---|---|
| `元問題番号` | 元の検定冊子の問題番号 |
| `採用` | RPGで利用可能なら `true`、画像・地図依存などで除外する場合は `false` |
| `遺産名` | 特定の世界遺産に紐づく場合の名称。一般知識問題は `null` |
| `国` | 遺産の所在国。一般知識問題は空配列 `[]` |
| `遺産区分` | `文化遺産` / `自然遺産` / `複合遺産`。該当しない場合は `null` |
| `問題文` | RPGで単独表示できるよう整理した問題文 |
| `選択肢` | 4択の文字列配列 |
| `正解` | 正しい選択肢番号。1始まり |
| `正答率` | 実際の検定での正答率（%） |
| `難易度` | 正答率に基づく1〜3の難易度 |
| `出典` | 元検定の実施回 |
| `問題文改定` | `そのまま` / `一部問題文を修正` / `除外` |
| `改定内容` | 修正した場合の内容。除外時は `除外理由` を使用 |

## 難易度基準

- 難易度1: 正答率90%以上
- 難易度2: 正答率75%以上90%未満
- 難易度3: 正答率75%未満

ゲーム側ではこの値をそのまま敵やイベントの難易度に利用できます。

## JavaScriptでの読み込み例

```js
const response = await fetch('./data/sekaken_4_2024_03_rpg.json');
const data = await response.json();

// RPGで利用可能な問題だけ取得
const usableQuestions = data.問題.filter(q => q.採用);

// 例: 日本の文化遺産・難易度2だけ抽出
const filtered = usableQuestions.filter(q =>
  q.国.includes('日本') &&
  q.遺産区分 === '文化遺産' &&
  q.難易度 === 2
);
```

## 正解判定時の注意

`正解` は配列のインデックスではなく、検定問題と同じく **1〜4** で保存しています。

JavaScriptで `選択肢` の配列インデックスと比較する場合は、次のように `+ 1` が必要です。

```js
const isCorrect = selectedIndex + 1 === question.正解;
```

## 今後のデータ追加

別の実施回も同じ形式で追加する場合、ファイル名は次の形式を推奨します。

`data/sekaken_4_YYYY_MM_rpg.json`

例:

- `data/sekaken_4_2024_07_rpg.json`
- `data/sekaken_4_2024_12_rpg.json`
- `data/sekaken_4_2025_03_rpg.json`

同じスキーマを維持すれば、複数ファイルを読み込んで問題プールとして統合できます。

## データ利用時の考え方

`問題文改定` と `改定内容` は、元問題からどの程度変更したかを追跡するための情報です。

正答率は元の検定問題に対する実測値なので、問題文を変更した問題では「完全に同条件での正答率」ではなく、難易度を判断するための参考値として扱います。特に、問題の意味そのものを変える改変は行わず、元の知識と正解を維持することを基本方針としています。
