# Phase 9 全国マップ UI/UX 決定事項

更新日: 2026-08-22

## 目的

Phase 9 の全国マップでは、以下を重視する。

1. 全国を気持ちよく移動できること
2. 27件の世界遺産の位置関係を把握できること
3. 現在地を見失わないこと
4. 遺産密集地でもマーカーがノイジーにならないこと

## 縮尺

- 全国マップの基準縮尺は **現行 Lab の 6倍** とする。
- 8倍でも視認性は成立するが、東北地方など世界遺産が少ない地域で、遺産が画面に長時間現れず移動が単調になる可能性があるため、6倍を採用する。
- 一方で、画面上に遺産が一つも見えない区間は許容する。『次はどこにあるのだろう』と探す探索体験として残す。
- 6倍化により移動距離が増えるため、全国版へ反映する際には移動速度・移動テンポを再確認する。縮尺決定と移動速度は別パラメータとして調整する。

## 遺産間の配置

- 遺産密集地でも、各遺産が別の目的地として視認できるだけの間隔を確保する。
- 位置関係は実際の地理を尊重するが、ゲーム上の視認性のための軽微な位置調整は許容する。
- 近接しすぎる複数遺産については、必要に応じて一つの研究センターが複数遺産を担当する構成を採用できる。
- 遺産そのものの位置関係と、研究センターの建物数は分けて考える。

## 地形表現

ファミコン版『ドラゴンクエストIII』のように、陸地を単色で塗るのではなく、地形自体をランドマーク認識に使う。

### 実地理に合わせるもの

- 代表的な山脈・山地
- 代表的な平野
- 大きな森林地帯
- 日本列島・主要島の形と相対的位置

全国版の地形作成時には、代表的な地形の位置関係を実際の日本地理にできるだけ合わせる。厳密な地形図の再現ではなく、小学生が『このあたりは山が多い』『関東には大きな平野がある』と感じ取れる粒度を目標とする。

### ゲーム性を優先する例外

- 世界遺産・研究センターの周囲は原則として草原など視認性の高い地形にする。
- 白神山地のように森林そのものが世界遺産であっても、研究センターの直近は草原にして建物を埋没させない。
- 遺産の本来の地形属性は周囲の広い地形で表現し、操作対象の直近だけ視認性を優先する。

このルールにより、地理学習としての納得感と、RPGとして目的地を見つけやすい画面を両立させる。

## ミニマップ

- 6倍マップでは日本全体が通常画面に収まらないため、現在地把握をミニマップで補助する。
- ミニマップは北固定を基本とする。
- 27件をすべて独立した点で表示してノイズを増やさない。
- 遺産が密集する場所は、店舗検索地図のクラスタ表示のように数値でまとめる方式を検証する。
- ミニマップの主目的は現在地と全国の大まかな分布把握であり、個々の遺産を精密に選択することではない。

## 都道府県

- 通常の移動画面で都道府県境を強く表示することは現時点では必須としない。
- ただし縮尺6倍で都道府県レベルの位置関係がどの程度自然に判別できるかは確認する。
- 都道府県名や境界を学習情報として明示する場合は、通常移動画面ではなく全国地図など別レイヤーで扱うことも選択肢とする。

## 次の検証

縮尺6倍を前提とした全国版 Lab で、以下を確認する。

- 北海道から九州まで移動した際のテンポ
- 東北など遺産の少ない地域で退屈しないか
- 近畿の密集地で遺産が視認できるか
- 代表的な山脈・平野が地理的に自然な位置に見えるか
- 遺産周囲を草原化した際に目的地が自然に目立つか
- 北固定ミニマップとクラスタ表示で現在地・分布を把握できるか
