### 不具合: 発見後の `?` と施設表示

#### r4まで

施設側で全国マップの座標を再計算していたため、`?` と施設が大きくずれて表示された。リビジョン表示を追加して `BETA r4 / PATCH r4` が確認できたことで、キャッシュではなく実装方式の問題と確定した。

#### r5

全国マップの Canvas が実際に `fillText('?')` へ渡した画面座標を取得し、施設を実座標へスナップする方式へ変更。

**実機結果**

- `?` と施設の位置ずれは改善した
- ただし、富岡製糸場を発見後に未発見の佐渡島の金山へ移動すると、佐渡の位置に「富岡製糸場と絹産業遺産群」の施設ラベルが表示された

**原因**

r5は `?` の実座標は取得できていたが、画面上の複数の `?` と27遺産のIDの対応付けを座標パターンから推測していた。画面内に候補が少ない場合、別の遺産IDを同じ `?` に割り当てる可能性があった。

#### r6

表示側も遺産ID基準へ統一。

- 発見状態は従来どおり遺産IDで管理
- 現在接触中の遺産名、センター退出時の `returnLockSiteId`、現在座標が遺産中心と一致する場合を「IDが確定できるアンカー」として利用
- IDが確定した遺産と実際の Canvas `?` 座標から画面座標の補正値を一度確定し、その補正を移動中も維持
- 発見済みIDごとに、そのIDの予測位置に一致する実 `?` だけを施設へ置換
- 未発見IDには施設を描画しない
- IDを安全に特定できない状態では、誤った施設名を表示せず元の `?` を残す

**実機結果**

- `?` は正しい遺産施設に関連付けられるようになった
- 富岡製糸場、佐渡島の金山などを移動しても別遺産のラベルへ誤置換される問題は解消

**状態**: r6 主要不具合は解消

### 次フェーズ改善メモ: センター退出直後だけ `?` に戻る

**現象**

「発見 → センターに入る → センターから出る」の直後、発見済み遺産が一時的に `?` として表示され、施設表示への更新に少し遅れがある。

**判断**

Golden Pathを止める不具合ではなく、再移動・再描画後は正しい施設表示になるため、ベータ完成を優先して今回は修正しない。

**次フェーズ候補**

センター退出イベント時に発見済み施設表示を即時更新し、`?` が再表示される瞬間をなくす。

### r7: 九州周辺の遺産座標修正

九州周辺の遺産座標を簡略地形と照合した。

- 屋久島 `(25,59)`：島上で問題なし
- 明治日本の産業革命遺産 `(24,53)`：九州本島上で問題なし
- 「神宿る島」宗像・沖ノ島と関連遺産群 `(26,50)`：九州本島上にあったため **`(24,49)` の北側浅瀬へ移動**
- 長崎と天草地方の潜伏キリシタン関連遺産 `(23,54)`：海マスだったため **`(24,54)` の西九州陸地へ移動**
- 奄美大島、徳之島、沖縄島北部及び西表島 `(23,62)`：島上で問題なし
- 琉球王国のグスク及び関連遺産群 `(20,65)`：島上で問題なし

確定済み全国6倍Lab本体は直接変更せず、ベータ専用ローダーで `area-map-game.html` と `japan-6x-map-lab.html` の2座標だけをr7実行時に上書きする。接触判定・Canvas上の `?`・施設表示パッチの3系統で同じ座標を使用する。

**実機結果**

- 宗像・沖ノ島は九州本島の内陸ではなく北側の海上に移動した
- 潜伏キリシタンは海上から西九州の陸地へ移動した
- 遺産IDとの対応付けは正しく維持されている

**状態**: r7 座標修正は確認済み
