### 不具合1: ピラミトン表示の先祖帰り

**現象**

ベータのチュートリアルで、確定済みデザインではなく以前の乱れたピラミトン表示になっていた。

**原因**

ベータが参照している `tutorial-lab-final.html` は画像シート切り出し版を使用していたが、その後に確定した `tutorial-design-baseline.html` の approved SVG Piramiton が反映されていなかった。

**対応**

ベータ専用 `beta-hotfix.js` から approved SVG Piramiton を適用する。チュートリアル本体の画面構成・文章・進行は変更しない。

**状態**: 修正済み・実機確認OK

### 不具合2: 発見後も `?` が残り、施設アイコンがずれる

**現象**

発見してセンターから戻ると、元の `?` が残り、施設アイコンが別の位置へ表示された。

**1回目の対応と結果**

外側の `area-map-game.html` 上にある施設DOMを半マス補正して `?` を覆う方式を試したが、実機では施設と `?` が大きく離れたままで改善しなかった。

**2回目の対応**

承認済み `japan-6x-map-lab.html` 本体は変更せず、ベータ専用 `beta-hotfix.js` から6倍マップ内部の `.camera` に施設レイヤーを注入する方式へ変更した。

- `?` と同じ計算式で施設位置を再計算
- 発見済み施設を同じカメラ内へ描画
- 旧来の外側施設レイヤーはベータ時のみ非表示

**2回目の実機結果**

見た目が1回目と変わらず、キャッシュの可能性が残った。

**3回目の対応**

`beta-hotfix.js` / `beta-save.js` の読み込みバージョンを更新した。

**3回目の実機結果**

表示は変わらなかった。

**4回目の対応**

画面右上に `BETA r4 / PATCH r4` のリビジョン表示を追加し、専用入口 `beta-r4.html` を作成した。

**4回目の実機結果**

`BETA r4 / PATCH r4` が表示され、最新版・最新パッチを正常に読み込んでいることを確認。それでも施設位置は `?` から大きくずれたままだった。

これにより、原因はキャッシュではなく、施設側でマップ座標を再計算している方式そのものにあると確定した。

**5回目（r5）の対応**

施設側で `?` の座標を推測・再計算する方式を廃止する。

- 全国マップの Canvas が実際に `fillText('?')` へ渡した画面座標をベータパッチで取得
- 発見済み遺産と実際の `?` 描画座標を対応付ける
- 施設アイコンを推定座標ではなく、実際に描画された `?` の座標へ直接スナップ
- 施設背面の草原マスクで元の `?` を覆う
- 確定済み6倍マップ本体の地形・縮尺・遺産配置・通常Labは変更しない

**状態**: r5 修正済み・実機再確認待ち
