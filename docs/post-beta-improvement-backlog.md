# ベータ後 改善・拡張バックログ

更新日: 2026-08-22

## この文書の位置づけ

娘向けベータ版 r9 は、最終確認が終わるまで実装をFreezeする。

この文書には、ベータ検証中に気づいた改善案・拡張案と、実際のプレイで得られたフィードバックを記録する。Golden Pathを止める不具合でない限り、r9には追加実装しない。

---

## 2026-08-22 娘による初回プレイフィードバック

### 全体

- **おおむね好評**。
- 現在の基本ループ「移動 → 発見 → センターで調べる → 腕試し → 次の遺産」は、今後磨き込む土台として成立していると判断する。

### 実プレイで出た改善点

1. **センター内のスティック操作が難しい**
   - 娘から明確に操作しづらさの指摘あり。
   - 事前の見た目調整より優先度が高い、実ユーザー由来のUX課題として扱う。
   - Beta 2では、スティックの入力範囲・感度・移動速度・センター内だけ別操作にする案などを比較検証する。

2. **腕試しが入口付近にあるため、先に挑戦してしまう**
   - 娘からも「奥側にした方がよい」との意見あり。
   - 本棚・調査員・展示などで知識を得た後、自然に腕試しへ向かう空間動線を優先する。
   - 強制順序にはせず、配置による誘導とする。

### 娘からの新アイデア：タイムアタック

- 最北端からスタートし、日本を南下しながら各遺産を回る。
- 各遺産の腕試しで **満点を取得**することを条件に進む。
- 最後に沖縄側の最南端まで到達するまでの時間を競う。
- 現在の「全国移動」「各遺産センター」「腕試し」を再利用できるため、将来のやり込みモード候補として相性がよい。
- 通常プレイとは分離した任意モードとし、学習の初回体験を急がせない設計にする。
- 将来的にはベストタイム保存、自己記録更新、条件違いのコース等も検討余地あり。ただし具体仕様は後フェーズで決める。

## A. Beta 2候補：操作感・視認性・演出の改善

娘による実プレイ結果を優先して判断する。

### 操作感【優先度高】

- **センター内のスティック操作を改善する**
  - 娘の初回プレイで「難しい」との指摘あり。
  - 入力範囲、感度、移動速度、斜め入力、指を置く位置と主人公の反応の分かりやすさを検証する。
  - 全国マップとセンターで同じ操作方式を維持すべきかも含め、Labで比較する。

### マップ表現

- **北海道の山を雪山表現にする**
  - 北海道らしい雰囲気を強める。
  - 現在の地形・縮尺は維持し、山タイルの見た目を地域ごとに調整する方向で検討する。

- **マップ移動を滑らかにする**
  - 現状は移動時の画面変化がカクカクして見える。
  - 主人公・カメラ移動を補間し、マス移動のルールは維持したまま視覚的には「ぬるぬる」動くようにする案を検討する。

- **沖ノ島を島として視認できるようにする**
  - 沖ノ島の位置に2マス程度の緑色の小島を追加する。
  - 必要に応じて周囲に浅瀬を置く。

- **開始地点から知床の `?` が見えるかを調整する**
  - 必要なら開始地点または見せ方を微調整する。

### 画面演出

- **発見時の代表画像をチューニングする**
  - 「その遺産だと一目で分かる」「視覚的インパクトが大きい」を優先する。
  - 27遺産それぞれについて発見演出用の代表画像を再選定・差し替えできるようにする。

- **画面切り替え時にエフェクトを付ける**
  - 全国マップ→発見→センター、センター→全国マップなどの遷移にフェード等を検討する。
  - 操作を待たせすぎない短い演出を基本とする。

- **センター退出直後に一時的に `?` へ戻る表示を解消する**
  - 発見済み施設表示へ即時更新し、違和感をなくす。

## B. Beta 2候補：研究センターUXの改善

### センター内レイアウト【優先度高】

- **腕試しを入口付近から遠ざける**
  - 現状は入口近くに腕試しがあり、入ってすぐ挑戦しやすい。
  - 娘の初回プレイでも「奥側にした方がよい」との意見あり。
  - 本棚・調査員・展示などを先に自然と体験し、その後に腕試しへ向かいやすい動線へ変更する。
  - 強制順序にはせず、空間配置によって「調べてから試す」を促す。

## C. 学習体験の強化

### 遺産ごとの展示

- **展示説明を図解化する**
  - チュートリアルの説明画面のように、文章だけでなく図・簡単な模式図・時系列などで説明できるようにする。
  - 各遺産の特徴、歴史的経緯、仕組みを視覚的に理解できることを目指す。

### 世界遺産そのものを学ぶ場所

- **遺産がない都道府県に「支部」を設置する案**
  - 個別遺産ではなく、世界遺産制度そのものについて学ぶ場にする。
  - 例：登録基準、文化遺産・自然遺産、危機遺産、暫定一覧表、世界遺産委員会、保全など。
  - 「遺産がない地域を移動する意味」を作る役割も持たせる。

- **世界遺産検定の過去問題を試せる場所を作る**
  - 各遺産センターの腕試しとは別枠にする。
  - 実際の検定形式・総合問題に挑戦する場として検討する。
  - 既に整備している過去問題JSONの利用を前提にする。

- **世界遺産の背景となる歴史・地理の基礎を学べる場を作る**
  - 個別遺産を理解するための前提知識を扱う。
  - 例：日本の時代区分、仏教伝来、城郭、産業革命、日本の地形・気候・プレート・植生など。
  - 個別センターへ大量の前提説明を詰め込まず、共通知識を別の場所に分離する狙い。

## D. やり込み・長期継続要素

- **やり込み要素を残す**
  - ベータでは外しているが、研究センターの成長・レベル・マスター等の既決定案を破棄しない。
  - 娘のプレイ結果を見たうえで、何を「もっとやりたい」と感じるかを基準に再設計する。
  - 単なる作業量ではなく、探索・学習・収集のどれを深めるかを検討する。

- **タイムアタックモード（娘発案）**
  - 最北端からスタートし、各遺産を巡って腕試し満点を獲得しながら、沖縄側の最南端まで到達する時間を競う。
  - 通常の学習・探索とは分離した、クリア後または一定条件達成後の任意やり込みモード候補とする。
  - 全国移動そのものをゲーム性として活かせる点、学んだ知識を高速で再確認できる点を評価する。
  - 具体的な解放条件、対象遺産数、ルート自由度、記録方式は後フェーズで検討する。

## E. 長期構想：日本版から世界版へ

- **将来的に日本以外の世界遺産へ拡張する**
  - 日本27遺産版を完成・検証した後の長期構想とする。
  - 国・地域ごとのマップ、地域特有の学習テーマ、世界史・地理との接続を視野に入れる。
  - 日本版のデータ構造・センター構造を、将来の世界展開を妨げない形に保つことを意識する。

## 実装開始の判断ルール

1. r9の最終確認が終わるまではコードをFreezeする。
2. 娘の実プレイで出た問題は、開発者側の推測より優先度を高く扱う。
3. まず「操作しにくい」「自然な動線になっていない」など基本体験を阻害するUXをBeta 2候補の上位に置く。
4. 見た目・演出・学習強化・やり込みは混ぜず、段階的に実装する。
5. タイムアタック等の新モードは基本ループを安定させた後の拡張として扱う。
