# iPad検証リンク集の運用

`test-links.html` を、iPad実機検証の固定入口として使用する。

## 基本ルール

- iPadでは GitHub Pages の `test-links.html` だけをブックマークする。
- 新しい Lab、プレビュー、本編確認用ページを追加したら、同じ変更で `test-links.html` にカードを追加する。
- 各カードには、少なくとも次を記載する。
  - ページ名
  - 状態（検証中 / 確定基準 / Main / 参考）
  - 役割
  - 実機で見る確認ポイント
  - 対象ページへの相対リンク
- LabをGitHub Pagesへ公開することと、本編へ採用することは別扱いとする。検証中Labを公開しても、APPROVEDや本編統合を意味しない。
- 確定したLabは状態を「確定基準」に変更し、後続案との比較に使えるよう残す。
- 役目を終えたページは削除せず、必要に応じて「参考」「旧比較基準」へ移す。

## iPadメモ

各カードのメモ欄はSafariの `localStorage` に保存する。`記入済みメモをまとめてコピー` で、ページ名付きのメモを一括コピーできる。

端末データの消去やプライベートブラウズ等ではメモが保持されない場合があるため、重要な内容はコピーしてChatGPTや開発記録へ移す。
