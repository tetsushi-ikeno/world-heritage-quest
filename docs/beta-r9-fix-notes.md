# BETA r9 修正メモ

更新日: 2026-08-22

## r8 実機結果

- センター内の本棚・腕試し等の体験済み状態は再読み込み後も保存された。
- 佐渡付近で終了したにもかかわらず、再開時は知床付近へ戻った。
- 発見済み遺産の施設は表示されたが、元の `?` と施設アイコンが再びずれて表示された。

## 原因

### 現在地

r8では `WHQMapAPI.setPosition()` を追加したものの、移動画面側に旧来の `posChip` 読み取り、`map.path` の再演フォールバック、外側からの座標管理が残っており、復元経路が複数存在していた。

### 発見済み施設

r8でも施設アイコン自体は全国マップCanvasとは別のHTMLレイヤーへ描画していた。そのため、Canvasのカメラ座標と外側レイヤーの座標系に差が出ると `?` と施設がずれる。

## r9 方針

### 現在地復元を一本化

- ベータ用全国マップへ `WHQMapAPI.getPosition()` / `setPosition()` / `refresh()` を提供。
- 移動画面の `playerPos()` はこのAPIを最優先で使用する。
- 再開時は `map.position` を `setPosition()` へ直接渡す。
- 通常復元では `map.path` を再演しない。
- ページ離脱 (`pagehide` / `beforeunload`) とタブ非表示時にも現在地を保存する。
- r9で正常復元後は古い `map.path` を空にする。

### 施設表示をCanvas内へ統合

- 旧 `centerLayer` と `beta-hotfix.js` の施設オーバーレイ描画を停止。
- `japan-6x-map-lab.html` をベータ用ローダーで読み込む際、世界遺産マーカーのCanvas描画処理だけをベータ用に差し替える。
- 未発見IDは従来どおり `?` を描画。
- 発見済みIDは同じ `(x,y)` に施設アイコン＋遺産名ラベルをCanvasへ直接描画。
- これにより `?` と施設で別の座標計算を持たない。

## 維持する仕様

- 確定済み全国6倍マップの地形・縮尺・追従方式は変更しない。
- ピラミトンの確定デザイン修正を維持。
- r7で修正した沖ノ島・潜伏キリシタンのベータ座標を維持。
- 沖ノ島に2マス程度の小島を追加する改善は次フェーズへ延期。
- センター退出直後に一瞬 `?` へ戻る違和感も次フェーズ候補として維持。

## r9 実機確認

1. `BETA r9 / PATCH r9` と表示される。
2. 一度現在地を移動し、分かりやすい場所で終了する。
3. 再読み込み後 `つづきから` を押すと、その位置へ戻る。
4. 発見済み遺産は最初から施設アイコン＋正しいラベルで表示される。
5. 同じ地点に元の `?` が残らず、施設との位置ずれもない。
6. センター内の本棚・展示・調査員・腕試しの `✓` が維持される。
