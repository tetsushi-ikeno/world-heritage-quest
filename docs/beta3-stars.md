# Beta3 星取得仕様

更新: 2026-08-31

## 基本ルール
- 星は「出題された問題そのもの」ではなく、各場所の「第何問目の枠」で管理する。
- 一度取得した星は、再挑戦で不正解でも失わない。
- 将来、問題プールが増えて毎回違う問題が出ても、同じ出題枠で一度正解済みなら取得済みとして扱う。

## 世界遺産
- 現在は1遺産につき3問。
- 第1問、第2問、第3問の3スロットを持つ。
- 最大は 27遺産 × 3 = 81星。
- 保存キーは遺産slug。

例:
stars.heritage.himeji = [true, false, true]

この場合、表示は「★ ★?」ではなく色で区別し、
第1問=黄色、第2問=グレー、第3問=黄色。

## ピラミトンスポット
- 現在は1スポットにつき1問。
- 最大は 19スポット × 1 = 19星。
- 保存キーはbranchId。
- 将来2問以上に増えた場合も配列を拡張して同じ方式で管理する。

例:
stars.branches.saitama-sakitama = [true]

## UI
- 未取得: グレーの星
- 取得済み: 黄色の星
- 出題画面では各出題枠の星を並べ、何問目が取得済みか分かるようにする。
- 全国マップの常時表示領域には、
  - 世界遺産 ★取得数 / 81
  - ピラミトンスポット ★取得数 / 19
  を表示する。
- 研究センターの常時表示領域にも両方の合計を表示する。

## データ互換
既存のBeta2セーブデータに stars がない場合は空の星データとして自動補完する。
