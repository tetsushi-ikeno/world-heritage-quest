# ピラミトン SVG LAB

## 目的

Phase 7.5で採用している画像版ピラミトンと、直線輪郭＋SVG顔・手の試作版を並べて比較し、SVG化を続ける価値があるか判断するための独立検証ページです。

ゲーム本体の `index.html` や既存Phaseコントローラは変更しません。

## 確認ページ

`/piramiton-lab.html`

## 確認できること

- 現行画像版 / SVG試作版の横並び比較
- 半透明での重ね合わせ比較
- 表情: 通常 / にっこり / びっくり / こまる / よろこぶ
- 動作: 通常 / 手をふる / 指さし / よろこぶ
- サイズ: 40 / 56 / 72 / 120 / 180 px
- 背景: 白 / 暗色 / マップ風 / ガイドUI風
- SVG輪郭線の太さ変更
- 参照画像の透明度変更
- アニメーションON/OFF
- 16pxグリッドON/OFF
- 56px / 72px / 96pxの実使用サイズプレビュー

## 判断基準

1. 元ピラミトンに見えるか
2. かわいさが残っているか
3. 56pxで目と口が読めるか
4. 72pxで感情が分かるか
5. 手をふる / 指さすが一目で分かるか
6. 現行画像版より視認性が高いか

「元ピラミトンに見える」と「画像版より視認性が高い」の両方が満たせる場合に、本体へのSVG導入を検討します。

## 実装上の分離

- `piramiton-lab.html`: 検証UI
- `piramiton-lab.css`: Lab専用スタイル
- `piramiton-lab.js`: Labの状態・操作・既存画像切り出し
- `piramiton-svg.js`: SVGキャラクター生成関数
- `piramiton-expr.js` / `piramiton-action.js`: Phase 7.5の現行画像資産を参照

SVG生成関数は `createPiramitonSVG(options)` としてLabから独立させているため、採用時はゲーム側へ移植可能です。
