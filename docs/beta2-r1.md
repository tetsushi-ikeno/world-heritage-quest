# Beta 2 r1

更新日: 2026-08-23

## 目的

Beta 1で成立したGolden Pathを維持したまま、娘の初回プレイで明確になった基本UXを優先改善する。

## Beta 2 r1で実施

1. 研究センター内は、スティック移動を残しつつ、展示・本棚・調査員・腕試しを直接タップしてもアクションできるC案に変更。
2. センター内の位置関係を、入口から奥へ向かって「展示 → 本 → 調査員 → 腕試し」と自然に巡りやすい配置へ変更。強制順序にはしない。
3. 全国移動中に「現在地：○○県」を表示。ゲーム用に簡略化した日本地図上の位置から都道府県を近似判定する。
4. センター退出直後の全国マップ再表示時は、地図更新完了まで短い遷移画面を被せ、未発見の `?` が一瞬見える違和感を隠す。

## 維持するもの

- 全国6倍マップ
- 主人公中心追従
- 27遺産
- 発見 → センター → 学習 → 退出 → 次の遺産、の基本ループ
- 現在地・発見状態・センター体験状態の保存
- チュートリアル
- Beta 1 r9は比較用として変更せず残す

## 確認ポイント

- センター内で対象物を直接タップしたとき、歩いて近づいた場合と同じ体験状態が保存されるか。
- センター内を普通に歩く場合も従来通り操作できるか。
- 腕試しが入口直後に目に入らず、展示・本・調査員の先にあると感じるか。
- 全国移動中、都道府県名によって自分が日本のどこにいるか把握しやすくなったか。
- 県境付近の表示切替が不自然すぎないか。
- センター退出直後に `?` の一瞬復活が見えないか。
