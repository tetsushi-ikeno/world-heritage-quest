# UI正本管理

このファイルは、世界遺産クエストで「現在どのUIが正本か」を判断するための唯一の参照先です。

## 運用ルール

- ファイル名、日付、Revision番号の大小だけで「最新」を推測しない。
- ここに `current` として記載されたものだけを正本として扱う。
- 新しいLabを正本に切り替えるときは、先にLabで確認・確定し、その後このファイルと `data/ui-current.json` を更新する。
- 本部や派生LabへUIを流用するときは、必ずこの正本を参照元として明記する。
- 正本未指定の画面については、既存ファイルから勝手に選ばない。
